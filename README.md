# Device-Drivers
Projects and informations related to Device Drivers

##Commands
- make
- make clean
- insmod hello_world.ko
- dmesg
- rmmod hello_world
- lsmod (Shows all loaded drivers)

##info

- my_dev will be in /proc/devices
- my_custome_driver will be in /proc/modules

- sudo ./test_chr_drv
